## Context

An internal mapping application that lets Dalkia engineers estimate the cost of extending a district heating network. Previously, this estimate required a site visit. The application already existed in Vue.js, but needed front-end expertise to raise its quality.

## What I did

- Led the front-end work
- Took part in scoping the requirements with the business teams
- Migrated gradually from Vue 2 to Vue 3
- Integrated the maps with ArcGIS
- Built the data visualizations
- Handled state management with Pinia and API calls with Axios
- Built the interface with Tailwind CSS
- Wrote unit tests with Vitest
- Worked with the back-end team on Python, Flask and SQLAlchemy

## Outcome

A network extension simulation that takes 5 minutes in the application, instead of a site visit.
