## Context

Savelys, a former subsidiary of Engie Home Services, was acquired by an investment fund and had to change its visual identity quickly. The goal: ship a Design System in under five months.

## What I did

- Chose Nuxt UI to start from ready-made components and only apply the brand identity
- Migrated the existing components, written in Vue.js and plain CSS, to this new architecture
- Organized the code with Nuxt Layers
- Built a component library documented in Storybook
- Wrote unit tests with Vitest
- Brought the components up to accessibility standards
- Migrated gradually to Strapi using the strangler fig pattern
- Set up CI on GitLab

## Outcome

A Design System delivered on a tight deadline, ready to carry the new Savelys identity.
