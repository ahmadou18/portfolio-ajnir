## Contexte

Deux ans chez Accor, sur les sites d'un groupe hôtelier international à très fort trafic. D'abord dans l'équipe Design System, puis dans l'équipe Homepage, où j'ai utilisé les composants que j'avais créés.

## Ce que j'ai fait

- Création de composants pour un Design System multi-marques : Ibis, Novotel, Sofitel, MGallery et Fairmont
- Intégration de ces composants sur la homepage
- Intégration front des composants de recherche Algolia
- Correction de bugs sur des composants existants

## Résultat

Refonte complète du site, avec des gains de performance sur les Core Web Vitals.
